Bash Commands I Have Learnt

1. touch

File creation

The touch command creates a new, empty file. If the file already exists, it updates the last modified time instead of changing its content. It is one of the simple ways to create a file from the terminal.

Syntax: touch filename

Example: touch notes.txt

Output: (no output - the file notes.txt is created silently in the current folder)

2. mkdir

Folder creation

The mkdir command creates a new empty folder at the location we give.

Syntax: mkdir foldername

Example: mkdir project

Output: (no output - the folder project is created in the current directory)

3. cd

Changing directory

The cd command changes the current working directory and moves us into another folder in the terminal.

Syntax: cd foldername

Example: cd project

Output: (prompt changes to show you are now inside ~/project)
